
# Python Contact Book

## Description
A beginner Python program for managing contacts.

## Features
- Add contacts
- View all contacts
- Search for contacts
- Delete contacts

## Technologies
- Python 3
- Dictionaries
- Loops and conditional statements

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Run `python contactbook.py`.

## What I Learned
- Storing data using dictionaries
- Using loops to create interactive menus
- Validating user input
- Handling missing contacts
